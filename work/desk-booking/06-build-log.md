- A run: RUNNING row (own transaction, unique index; a lost race counts as "already running", AC14.8) then gate `requireSuccessFactorsReadyForSync` then all pages in memory (200 per page, 500-page cap) then bad-data checks (`EMPTY_RESPONSE`, `FIELDS_MISSING`) then one apply transaction then the leaver hand-over then the run row SUCCESS with counts. Codes: `SF_UNREACHABLE`, `SF_AUTH`, `SF_ERROR`, `EMPTY_RESPONSE`, `FIELDS_MISSING`, `DROP_TOO_LARGE`, `TOO_MANY_PAGES`, `APPLY_ERROR`, the two B5.9 codes. Messages never carry a body, name or email.
